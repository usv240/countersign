How Countersign works

One job, ten rules, and nine places that enforce them. Every rule is enforced outside the model at least once, so a model that is fooled still cannot send.

The job, in five steps

  1. A warning arrivesCode fetches it from the National Weather Service. Nothing typed or pasted counts as official.
  2. Paging startsStep Functions pages Officer A at once, then B, then C, then the state desk. The agent cannot stop it.
  3. The agent draftsClaude Sonnet 4.6 on the AgentCore managed harness writes the alert in English and Spanish, inside the warning's area.
  4. Code checksEvery draft is checked against all ten rules. A test copy goes to the test channel and a correction is staged.
  5. A person signsThe officer sees the source and the draft, never an opinion. Only then does the sender, after two checks, publish live.

Architecture

Left of the wall is everything the agent can reach. Right of it is what only a person can trigger. The wall is IAM, tested directly with the IAM policy simulator.
