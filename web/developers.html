Request

FieldTypeMeaning
county_geoidstringThe sending office's area. 5 digits for a county, 2 for a state. Required unless preset_id is given.
warningstring or objectThe source: CAP 1.2 XML, an NWS GeoJSON alert, or an OpenFEMA record. Always treated as unsourced.
live_warning_idstringInstead of warning: an active NWS alert id. Countersign fetches it itself, so it counts as official.
preset_idstringInstead of warning: one of the demo cases.
proposalobjectThe alert you plan to send: text_360, text_90, text_360_es, alert_class, polygon, geocodes, action_ids, approvals, correction_staged, requested_by. Omit to check the warning as it was sent.
area_modestringOptional: warning (clip the warning's polygon to the county), code (county code only) or none.
local_placesstring[]Place names your office uses, such as rivers and roads, so they are not flagged as invented.
include_geometrybooleanAlso return the county outline and the warning polygons.

Response

decision.outcome is one of blocked, needs_1_approval, needs_2_approvals or send_ok. decision.checks holds one entry per rule with status pass, fail, warn or info, and a plain message. decision.facts holds the area, the share of the county and the people it reaches.

{
 "decision": {
  "outcome": "needs_1_approval",
  "approvals_required": 1,
  "summary": "Ready for review. Needs 1 approval from distinct officers.",
  "checks": [{ "rule": "R3", "name": "A real map area, inside the county", "status": "pass",
              "message": "1217.7 km2, 42.6% of Kerr County, inside the warning polygon. About 22,416 people." }],
  "facts": { "people_reached_est": 22416, "share_of_jurisdiction": 0.4262 }
 },
 "source": "Preset: an unmodified public record",
 "usage": { "calls": 1, "daily_limit": 2000 }
}

Errors and limits

StatusWhen
400The body is not valid JSON, the county code is not 2 or 5 digits, or the warning cannot be read. The message says which.
401No x-api-key header, or the key is unknown or revoked.
404No such route or preset.
429Over 2,000 calls today for this key, or 500 keyless checks for this address. API Gateway also throttles at 20 requests a second.
500Our fault. The response names the error type, never internals.

Agents and MCP

Countersign's own agent reaches its tools through AgentCore Gateway over MCP. That gateway admits one IAM role, the agent's, and its Cedar policy denies every other caller by default, so it is deliberately not public. To give your own agent the same rule check, call POST /v1/evaluate as a tool before it does anything with an alert: the result is the same code.

The rule engine is plain Python with one dependency (Shapely). The code repository lets you run it offline, rerun every benchmark number without an AWS account, and deploy the whole stack with one command.
