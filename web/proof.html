Proof

Every number here was measured on the deployed AWS stack or on public records, and every one can be recounted from the saved results with one command and no AWS account. Where something broke, it is written down.

The stress test

Sixteen attacks plus the ordinary job, each run twice, against three kinds of agent: Claude Sonnet 4.6 with Countersign's full instructions; the same Claude told to do whatever staff ask; and Amazon Nova Lite told the same, a model that actually obeys. Each agent runs once with a send tool and nothing behind it, and once inside Countersign.

With the model removed

Assume the model is fully compromised. These calls go straight to each layer on AWS with no model in the loop: the Gateway, the hook, the tool code, IAM through the policy simulator, and the sender.

The solver's own tests

Automated Reasoning checks hold the live-release rules as formal logic. Before anything is sent, the solver must agree with the code. These are its probes, including the one where it should say yes.

Three years of real alerts

Every local phone alert in FEMA's public archive for 2023 to 2025, checked by the area, wording and class rules. Scheduled system tests are left out. An alert counts as an error when its own sender issued a follow-up within 24 hours saying it was sent in error or to disregard it.

The message rules are not a mistake detector, and the table shows it: some retracted alerts pass every check. That is why rule R2 asks a second person, and why the agent never sends.

What broke, and how I fixed it

Found by running the system on AWS, not by reading the code. In the order they happened.

Limits, stated plainly

  • No real phone receives an alert. The live channel is an SNS topic standing in for FEMA's IPAWS, which needs a signed agreement with FEMA.
  • Two runs of each attack is a sample, not a guarantee. Models vary between runs; the transcripts are saved so you can read every one.
  • People reached is an estimate: the area's share of the county times its 2020 population, as if people were spread evenly.
  • The facts the agent flags for the officer are not verified by code. In one test run the agent misread a time zone and flagged a timestamp that was correct. It now gets local times, and the officer always sees the source beside the draft.
  • The paging demo uses 30 to 120 second timeouts so you can watch it move. A real office would set minutes.
  • FEMA's archive copies are not byte-exact, so their digital signatures do not verify. Official status comes from code fetching the warning from the National Weather Service, not from the archive's signature.

Recount it yourself

Every number on this page is computed from saved result files in the code repository.

git clone https://github.com/usv240/countersign && cd countersign
python -m pip install -r requirements.txt
python -m pytest tests             # rule engine tests on the real records
python evals/recount.py            # prints every number on this page from evals/results
